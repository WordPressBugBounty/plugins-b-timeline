Timeline helps you create and display organized vertical and horizontal timelines on your WordPress website. Present important dates, milestones, events, and stories in a visual format that visitors can follow easily.

With the free Timeline plugin, you can create vertical or horizontal timelines, control the starting position, choose how many horizontal items appear, customize timeline titles with HTML, and embed your timelines using shortcodes.

Need more advanced timeline layouts? Timeline Pro adds Gutenberg timeline blocks, ready-made templates, animations, dynamic WordPress post timelines, and specialized layouts for company histories, careers, events, product roadmaps, and more.

### Why Use Timeline?

**Timeline** makes it effortless to create responsive, customizable, and interactive timelines that fit perfectly inside posts, pages, and widgets. Whether you're displaying a personal journey, company history, project milestones, or event schedules, Timeline gives you complete visual storytelling freedom.

The plugin offers vertical and horizontal layouts, supports start alignment, custom HTML titles, and includes a powerful shortcode generator for quick embedding. Choose the layout you like, add timeline items, customize the visuals – and publish. No hassle. No technical knowledge required.

### Free Features

- **Vertical & Horizontal Layouts:** Switch between vertical and horizontal timelines with a single click.

- **Responsive & Mobile Friendly:** Timelines automatically adapt to all screen sizes.
- **Shortcode Generator:** Quickly embed a timeline anywhere using a shortcode.
- **Lightweight & Fast:** Clean code, optimized performance, and minimal footprint.

== Installation ==

This section describes how to install the plugin and get it working.

### Install from WordPress

1. Go to **Plugins → Add New**.
2. Search for **b timeline**.
3. Click **Install Now**.
4. Click **Activate**.
5. Go to **Timeline → Add New**.
6. Create and publish your timeline.

### Manual Installation

1. Download the Timeline plugin ZIP file.
2. Go to **Plugins → Add New → Upload Plugin**.
3. Upload the plugin ZIP file.
4. Click **Install Now**.
5. Activate the plugin from the **Plugins** screen.


== Frequently Asked Questions ==

= Does it work with any WordPress theme? =

Yes, it will work with any standard WordPress theme.

= How many times can I reuse a shortcode? =

You can use unlimited times as you want.

= Does Timeline support Gutenberg? =

Yes. Timeline Pro includes a Gutenberg Timeline block for creating and customizing timelines directly in the WordPress Block Editor.

= Can I create a timeline from WordPress posts? =

Yes. Timeline Pro includes a Dynamic Post Timeline block that can generate timeline content from WordPress post types and filter content by taxonomy, terms, and author.

= Can I add animations to timeline items? =

Yes. Timeline Pro includes animation options for timeline items.

= Where can I get support? =

You can post your questions on the [support forum here](https://wordpress.org/support/plugin/timeline-block-block/)

= Where do I report security bugs found in this plugin? =

Please report security bugs found in the source code of the Timeline – Create And Display Timeline Contents plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fc6a0-312a-4aca-b776-c4f5432f294d). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
